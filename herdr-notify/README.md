# herdr-notify

A CodeBuddy Code plugin that reports session state to [Herdr](https://herdr.dev/).

- **Herdr app / herdr-core**: OSC 7501 over the pane's pty (works over SSH).
- **Herdr TUI**: `herdr pane report-agent`.

## Install

```bash
codebuddy plugin add ./herdr-notify --scope user -y
```
