# herdr-notify

A CodeBuddy Code plugin that reports session state to [Herdr](https://herdr.dev/).

- **Herdr app / herdr-core**: OSC 7501 over the pane's pty (works over SSH).
- **Herdr TUI**: `pane report-agent`, including native session resume.

## Install

From the CodeBuddy marketplace:

```text
/plugin marketplace add szkane/codebuddy-herdr
/plugin install herdr-notify@codebuddy-herdr
```
